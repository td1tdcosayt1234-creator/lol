# ❄ FROSTPINE — Where Forest Meets Ice

Full cool static web: forest + ice + aurora fusion theme.

- No build step, no libraries — pure HTML/CSS/JS
- Canvas snowfall + fireflies + aurora glow
- 3 themes: 🌲 Forest / 🌌 Aurora / 🧊 Ice (buttons or keys F/I/A)
- Temperature Explorer slider (-20°C to +22°C) changes whole scene live
- Realms, Creatures, Seasons timeline, custom cursor glow

Open `index.html` directly or serve statically.

Built via CodeBridge MCP (`push_code`).
